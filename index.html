Software Libre Taldea, 2021-2022 kurtsoan sortutako talde bat da, Donostiako Informatika Fakultateko lagun batzuen ekimenez. Software, hardware eta kultura librean dugun interesak bultzatu gintuen talde hau sortzera, gai hauen inguruan eztabaidatzeko talde baten beharra ikusten genuen. Nahiz eta taldearen sorrera Informatika Fakultatean eman zen, taldearen helburuak betetzeko, fakultatetik kanpo eta fakultatearekin lotuta ez dagoen jendearekin jardun nahi dugu.

Gure Helburuak

  • Software librearen erabiliera bultatzea eta aldarrikatzea fakultate barnean eta kanpoan.
  • Software librearen garrantziaz konzientzia piztea eta software propietarioaren kaltea ikustaraztea.
  • Software librea eta bestelako teknologia libreen inguruan eztabaidatzeko talde inklusibo bat izatea.
  • Software eta kultura librearen inguruko ekitaldiak, tailerrak edo bestelako ekintzak antolatzea.
